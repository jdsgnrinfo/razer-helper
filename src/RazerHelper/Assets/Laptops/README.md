# Laptop pictures

The System page shows the laptop's picture at the left of its model. The
pictures are built into the exe from this folder.

- **Format:** PNG with a transparent background, the laptop open and seen
  from the front, trimmed to its edges. About 470 × 300 px or larger (three
  times the card's 156 × 100 room, so it stays sharp at 300% scaling).
- **Names:** line, size, edition and year, in lower case with dashes. The app
  uses the closest one there, so a picture for a size covers every year of it:

  | Laptop                          | Tried in order                                              |
  | ------------------------------- | ----------------------------------------------------------- |
  | Razer Blade 15 Base (2020)      | `blade-15-base-2020`, `blade-15-2020`, `blade-15-base`, `blade-15`, `blade` |
  | Razer Blade 16 (2023)           | `blade-16-2023`, `blade-16`, `blade`                        |
  | Razer Blade Stealth 13 (2020)   | `blade-stealth-13-2020`, `blade-stealth-13`, `blade-13-2020`, `blade-13`, `blade` |

With no picture for the laptop, the page draws one in fine lines.
